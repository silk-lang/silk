# Portable ordinary TypedBody prototype (source only)

Tree: `.scratch/shared-typed-bodies`, base `85ba82e` (V22, CacheImage; no Bundle import).

Ownership: parallel_semantics owns BodyCapsule.silk, BodyWire.silk, and TypedBody.withPortableEnvironment; edit_overlap owns BodyTypes.silk; worker_forks owns Semantic/arena/guard integration.

Frozen top-level interface:

- `BodyCapsule.encode(body: &TypedBody, context: &[u8]) -> Option<Bytes> !OutOfMemoryError ?Allocator`
- `BodyCapsule.decode(bytes: &[u8], expectedContext: &[u8]) -> Option<TypedBody> !OutOfMemoryError ?Allocator|Types`

The codec is not a proof of typing or freshness. Exact application/profile/source context and a seal over payload+guard must be checked by the integration, then the complete provider dependency graph imported before publishing an answer. ContractTyped remains ContractTyped. Unsupported private type evidence, bounds, malformed bytes, wrong context, unknown discriminants and invalid local references produce no capsule/answer; the ordinary provider remains available. Decode may leave harmless immutable intern entries after later failure, but never installs a query answer or graph dependency.

Encoding traverses body fields twice through pure callbacks: a bounded count pass and a preallocated owned atom-plan pass. Nodes/locals and origins are body-local; every Type/Lifetime/Application/StaticData/Declaration uses a per-capsule structural dictionary and is reconstructed/interned by the receiver. Atom planning safely traverses nested Shared lists/bodies and retains only owned clones, never borrowed pointers across effects. The effectful dictionary encoding follows after the callbacks. Nested body and environment metadata, exact retention, signature/runtime requirements, static iterations, resolutions, foreign declarations and interface operation metadata are retained (last two regenerated by TypedBody.make from decoded nodes). No re-materialization of already checked environment projections occurs.

Limits: 512KiB emitted capsule (matching arena admission), 16MiB decoder hard input cap; 65,536 cumulative body nodes; 16,384 cumulative body locals and dictionary entries; 128 recursive structural scopes; 1,048,576 total codec work steps/plan atoms and cumulative allocation-bearing entries. Decoder container reservations are additionally bounded by remaining bytes before allocation. Planning memory is linear in actual bounded atom count plus retained handles, rather than allocating the maximum up front. Large union decoder branches are split into separate functions to keep unoptimized recursive stack frames small.

Focused tests drafted: cross-TypeTable byte-stable roundtrip preserving Stage, origins/local region metadata, runtime/signature requirements, iterations and resolutions; exact-context mismatch; trailing/truncated bytes; invalid body root; exhausted output and truncated giant container rejected before allocation; recursion bound. BodyTypes owns structural type/application/region/static test coverage. Isolated focused compile is active in assigned shared slot2; input snapshots/attempt logs are retained. Full Semantic/arena integration remains separate.
