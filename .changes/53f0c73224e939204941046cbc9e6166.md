`SystemClock.now` returns a `silk.time.instant` `Instant` and `MonotonicClock` works in the new `silk.time.mark` `Mark`, so system time and monotonic time are different types; the old `silk.system.system_clock` `Instant` is removed.

## Migration

Import `Mark` from `silk.time.mark` wherever a `MonotonicClock` mark or deadline was typed `Instant` (`Option<Instant>` deadlines become `Option<Mark>`), and import `Instant` from `silk.time.instant` for system time. Replace `SystemClock.make(s, n)` with `Mark.make(s, n)` or `Instant.make(s, n)`, `SystemClock.seconds(&x)` with `x.seconds()` on a `Mark` or `x.unixSeconds()` on an `Instant`, and `SystemClock.nanoseconds(&x)` with `x.subsecondNanoseconds()`, which is a `u32`. Both types are `Copy` and compare with `<` and `==`, so helper functions that copied or compared them can go. Platform readers: `NativeClock.now(true)` is `NativeClock.now()` and `NativeClock.now(false)` is `NativeClock.systemNow()`; the same holds for `WasiClock`, `WindowsClock` and `JsHost`.
