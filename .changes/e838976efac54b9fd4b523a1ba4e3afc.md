## Migration

Compare paths with `path.matchesText("idle_seconds")` instead of `path.view() == "idleSeconds"`: a path is now segments, and its text uses wire names. A custom `Schema.shape` returns `ShapeOf<Self>`; `Schemas.shapeVia` already does.
