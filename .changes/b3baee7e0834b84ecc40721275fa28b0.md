`silk.time` carries the IANA time zone database (2026e): `BundledTimeZones`, `ZoneBundle` for a bundle that the program supplies, `OsTimeZones` and `OsLocalZone` on Windows, WASI and JavaScript hosts, `PreferSystemTimeZones`, and `silk.time.now`.

## Migration

A JavaScript host that instantiates a module using `OsLocalZone` without `stdlib/host/wasm-runner.mjs` must supply the import `silk.time-zone`.
