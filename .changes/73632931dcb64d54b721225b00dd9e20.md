Make Logger ambient and send warnings and errors to the default platform logger.

## Migration

Remove `? &mut Logger` and `LogError` from logging functions. To collect events, put the provider in an `Arc<P>` and run the effect with `Effect.provideAmbient<Logger>(&handle)`. Read an in-memory logger through `handle.get()`. Its constructor now needs an allocator. Check `Logger.attempts` to count events that exceeded its capacity.
