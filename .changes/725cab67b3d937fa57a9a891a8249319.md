Add `silk.npm.ini` and `silk.npm.config` to read `.npmrc` files and npm's layered configuration (environment, project, user, global), with `${VAR}` expansion, scoped registries and registry credentials, and `HostInput.variableNames` to list environment variables.

## Migration

Every `impl HostInput for T` must add `variableNames: T.variableNames`, an `effect fn variableNames(self: &mut T) -> List<Bytes> ! HostInputError | OutOfMemoryError ? &mut Allocator` returning the environment variable names (an empty list is fine for a test provider).
