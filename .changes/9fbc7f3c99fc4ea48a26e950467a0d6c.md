Add JSON Schema validation for drafts 4, 6, 7, 2019-09, and 2020-12, including TOML schemas and instances, exact JSON numbers, and native Unicode regular expressions.

## Migration

`JsonNumber` now owns exact decimal text and no longer implements `Copy`; borrow it with `JsonNumber.view` or move it explicitly. Match the new `JsonNumber.Decimal { text }` variant in exhaustive matches.

`JsonDocument.asNumber` now returns `Option<JsonNumberView>` instead of `Option<JsonNumber>`. Import and match `JsonNumberView` for borrowed numbers; call `run JsonNumberView.toOwned(view)` when independently owned storage is needed.
