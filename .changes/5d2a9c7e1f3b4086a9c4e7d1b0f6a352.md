`bench fn name(b: Bencher)` declares a benchmark that loops on `b.next()`; a program whose `main` calls `silk.bench.bencher.Benchmarks.main()` runs the benchmarks its entry file imports, alone or driven by a benchmark task, and `silk task bench --save <name>` and `--baseline <name>` compare a run with a kept one.
