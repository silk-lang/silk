Hold every package to its `silk-version`, the root and each workspace member included: a stable release builds packages pinned to its own release line, a dev release builds only packages pinned to that exact release, and `--ignore-silk-version` on `silk build`, `check`, `test` and `run` builds the others anyway with a warning.

## Migration

Every package needs a `silk-version`; set one with `silk set <version>`, or add `silk-version = "<version>"` to `[package]`. In a workspace, write it once under `[workspace]` and remove `[package].silk-version` from each member, which Silk now refuses beside the workspace's pin. A dev release builds only packages pinned to that release, so re-pin dependencies written for another dev release, or pass `--ignore-silk-version` to try them.
