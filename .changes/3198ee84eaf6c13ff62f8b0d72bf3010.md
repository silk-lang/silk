`RegexShape.of` (`silk.text.regex_shape`) reads a regex pattern in static code: whether `Regex.compile` would accept it, its error and offset, and its capture groups with names and which can be left unset. `Regex.compile` now rejects binary Unicode properties the engine has no table for (such as `\p{ID_Compat_Math_Start}`) with an error instead of compiling them.
