The language server runs `silk plan` with your own permissions instead of a sandbox, so the editor's compilation requests match `silk build`, for example when a plan looks for Homebrew libraries. It still runs a plan only in a trusted workspace. A project whose `tasks.silk` has its own `Plan` command is asked about once: the editor shows Allow and Not now, and records Allow under `$SILK_HOME/editor-plans`, where every worktree of the repository shares it. Until then the editor reads the requests the last build or plan saved, and says when `tasks.silk` is newer than they are.
