`silk task` and `silk task --help` list every task with its options and arguments, and `--help=json` prints a command's help as one JSON object, in `silk.cli` programs (`Cli.writeHelpJson`), `silk task` and the project commands.

## Migration

`Parsed.Help` has a `json` field. Match it as `Parsed.Help { command, json }`, or `Parsed.Help { command, .. }`, and call `Cli.writeHelpJson<T>(command)` when `json` is set.
