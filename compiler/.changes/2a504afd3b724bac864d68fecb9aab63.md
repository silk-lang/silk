Stricter declaration checks for Drop and Copy impls, C symbol names, C symbol conflicts and C-layout structs.

## Migration

Fix declarations now rejected at `silk check`: `impl Drop` must declare exactly `fn drop(self: &mut Self) -> ()`, `impl Copy` declares no members, link names must be ASCII identifiers not reserved by the compiler, and C-layout structs take no type parameters and only C-compatible fields.
