A directory's `mod.silk` is now the module its directory path names, like Rust's `mod.rs`: `import shapes` reads `shapes.silk` or `shapes/mod.silk`, whichever exists, so a barrel module can gather its directory's modules with `pub import`. `[package].exports` entries name barrels the same way. A path with both files reports MOD0005, and an import written as `shapes.mod` reports MOD0006 (MODULE-007).
