Group the standard library into category directories, such as `silk.collections.list` and `silk.json.value`.

## Migration

Replace each import path on the left with the one on the right. Where a namespace import's last segment changed (for example `import silk.toml_scanner` now binds `scanner`), rename its uses or add `as` with the old name.
