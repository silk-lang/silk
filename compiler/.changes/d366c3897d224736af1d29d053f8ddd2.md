Raw pointers such as `*mut Node` and `?*const u8` are now ordinary structural union members, so `fn find() -> *mut Node | Missing` returns either one, and a match selects the pointer with `*mut Node node =>`, `?*const u8 bytes =>`, or a `type` alias of the pointer. A generic handler passed by name to `catchFailure` or `Effect.catch`, such as `effect fn caught<E>(error: E) -> Caught<E>`, is now instantiated at the selected failure type instead of reporting SEM0067.
