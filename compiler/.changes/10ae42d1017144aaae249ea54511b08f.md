`a == b` on two values of a type that implements `Equal` (or `a < b` with `Order`) reports SEM0135 with a hint: "Operator == does not accept (main.Id, main.Id); compare shared borrows, as in `&a == &b`". These interfaces compare references, so the values must be borrowed. A type with no such implementation keeps the plain message.
