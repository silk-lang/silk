Errors about tests and effects say what to write:

- SEM0066 in a function that is not an `effect fn`: "This `run` can fail with `AssertionError<'static>`, but only an effect function can declare failures; write `test effect fn` and add `! AssertionError<'static>` to its signature" (`effect fn` outside a test).
- SEM0062: "Only an effect function can declare failures; write `test effect fn` instead of `test fn`", or requirements and `effect fn` as the case may be.
- SEM0218 names the part of a test that is not allowed, such as "Invalid test declaration: a test takes no parameters; the test runner calls it with none", or a `-> bool` result or a type parameter.
