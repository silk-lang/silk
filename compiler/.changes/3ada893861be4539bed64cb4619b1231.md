Optimized code gets smaller frames and fewer wrapper calls. A failing call's failure slot and its diagnostic context now end their stack lives on the call's success edge too, so LLVM can share those slots across the calls of a function: the SilkJS interpreter's frame goes from 9.7 KB to 728 bytes. Drop glue is no longer forced out of line, so a drop that is only a tag check inlines. A function that takes a callable or an `Effect` parameter, like `Effect.map` or `catchAll`, asks to be inlined unless its own inline clause says otherwise (FUNC-003).
