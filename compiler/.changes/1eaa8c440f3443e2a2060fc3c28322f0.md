Add HTTP/2 client and server connections (`silk.http2`) and a buffered driver over plain or TLS transports (`silk.http2_connection`). Support HPACK, concurrent streams, flow control, informational responses, trailers, CONNECT tunnels, server push, protocol errors, and graceful GOAWAY. The native conformance gate checks Node/nghttp2 interoperability, authenticated h2 ALPN, and all strict h2spec cases.
