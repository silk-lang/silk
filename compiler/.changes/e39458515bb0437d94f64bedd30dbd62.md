A `mut fn` binding passed to a `mut fn` or `once fn` parameter is lent for that call only, so it stays usable afterwards, and passing the same binding twice to one call is now rejected (OWN0010) instead of aliasing its state. OWN0018 names the borrowed local and the fix, SEM0210 for a callable result suggests `fn<'static>(...)`, OWN0001 after a consuming bound method names the binding, SEM0037 for a callable binding explains that each function has its own type, and SEM0087 suggests `drop`.
