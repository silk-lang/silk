An `if` value parses as a call argument and an array element, as in `twice(if n > 1 { 3 } else { 4 })` and `[if n > 1 { 3 } else { 4 }, 5]`, instead of a PAR0001 cascade. `if` branches that cannot join report SEM0049 naming the branches of the `if`, not match arms, and note that a block ending in `let` produces `()`. A value left at the end of a statement `if` branch reports SEM0087 saying the `if` is a statement.
