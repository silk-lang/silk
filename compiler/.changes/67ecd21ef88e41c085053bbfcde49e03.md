`silk changes` moves to sew as `sew change`, and `sew change patch|minor|major "Summary"` replaces `silk changes add`. The other subcommands (`status`, `version`, `release`, `snapshot`, `since`, `recover`) are unchanged. The compiler no longer has a `changes` command and no longer links the changeset package. A manifest's release settings now live in `[release]`. `[changes]` stays readable as its earlier spelling until the repository's own manifests move after the next seed, and a manifest that writes both is refused. Generated version modules now say `Auto-generated by sew change version`.
