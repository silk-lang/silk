The standard library now decodes LZMA-alone, raw LZMA2, and XZ streams with explicit resource limits. XZ verifies block checksums, index records, and footers, and supports concatenated streams. `silk.deflate.Deflate.encode` compresses complete buffers to raw DEFLATE, zlib, or deterministic gzip using LZ77 matches and fixed Huffman codes.
