Format template errors say what to write. A lone `}` asks for `}}`; `{:x}` or `{:e}` on the wrong type says the placeholder needs an integer or a float; a plain value passed for the arguments says to borrow it; and a template error no longer carries a note into the standard library. A `w$` or `.p$` field can be any integer, so `&.{w: 5}` needs no `usize` annotation; a negative one traps.
