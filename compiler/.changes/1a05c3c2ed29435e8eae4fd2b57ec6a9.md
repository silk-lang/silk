sew answers a first word one edit away from `use`, `set` or `update` (such as `sew uze`) with a suggestion instead of forwarding it to the compiler. `sew use <version>` replaces a version directory that lost its `bin/silk`, `sew use uninstall` removes one, and an install that holds the lock removes staging directories interrupted installs left. A member's own `silk-version` that disagrees with its workspace's pin is named in a note on every forwarded command and in `sew use which`. `sew set` names the version it replaced on its result line and no longer suggests `silk changes since`, which did not work in user projects. A `SILK_TOOLCHAIN` that is not a version is a usage error (exit 2) like a malformed `+<version>`, and `sew use list` without a usable `SILK_HOME` says so instead of reporting no versions.
