On Linux, `ChildProcess` starts a child with `posix_spawn` instead of `fork`, as it already did on macOS, so starting a child no longer copies the parent's page tables. A build hands its codegen units to Clang biggest first, each to the least loaded thread. A cold debug build of the compiler spends 9.5 s in Clang instead of 24 s.
