Check captured call inputs against the selected operation's written Effect environment bounds, and preserve covariant inference for omitted Effect environments.

## Migration

A written Effect environment constrains the captured reference's outer access lifetime as well as its referent contents. Give caller signatures the required lifetime relationship; immediately running an Effect does not waive that obligation. Interface calls use the selected operation's contract even when its implementation has weaker bounds. Some invalid calls now report a lifetime-bound error at the source operand instead of an unresolved ownership result.
