`sew update self [--dev]` replaces sew and its `silk` twin in `$SILK_HOME/bin` with the newest signed release (the newest dev release with `--dev`, or while no stable release exists) and installs no Silk version. install.sh now installs sew as `$SILK_HOME/bin/sew` with `$SILK_HOME/bin/silk` a second name for it. `sew use uninstall` says when the current project pins the version it removed.
