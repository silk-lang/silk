A line in a match that starts with a negative integer pattern, as in `-1 => 2`, now begins a new arm instead of continuing the previous arm as a subtraction. Common match mistakes are one PAR0010 each that names the fix: `=> return x`, a literal in a field pattern, a comma between arms, and a bare name as a pattern. SEM0046 names the missing field, SEM0042 names the type and the union's members, SEM0040 names the member the target lacks, SEM0224 says to drop the braces, and SEM0087 for an unrun Effect gives its advice once.
