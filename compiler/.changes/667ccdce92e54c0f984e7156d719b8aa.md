A C import or export whose parameter or result is a plain `struct`, a `string`, an array or another type with no C form now reports SEM0187 at that parameter of the declaration, instead of `unsupported[ForeignAggregate]` at each call. A plain struct is told to declare its layout: "Point has no C layout; declare it `extern "C" struct` to pass it to C by value". Primitive and vector lanes of an import are still checked where it is called, because they depend on the target.

SEM0206 names the field, the record and the field's type: "Field ok of C-layout record Flag has unsupported type bool".
