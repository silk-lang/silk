A call that cannot pass static arguments yet now reports SEM0249 with the call to write instead of a generic "not supported" error. Method syntax on a method with `static` parameters (`leaf.own(spec)`) says to write the type-qualified call `Leaf.own(&leaf, spec)`. A call to an interface operation with `static` parameters, through the interface or with method syntax, says to give the implementing type an inherent function with those parameters and call it by its type-qualified name.
