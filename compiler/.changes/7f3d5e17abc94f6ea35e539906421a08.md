Remove the anonymous `fn(x: T) -> R { ... }` expression: lambdas are the only anonymous functions, and the old form reports PAR0010 with the lambda spelling.

## Migration

Write each anonymous function as a lambda: `fn(x: T) -> R { ... }` becomes `|x: T| -> R { ... }`, `fn() -> R { ... }` becomes `|| -> R { ... }`, and `effect fn(x: T) -> R ! E ? Q { ... }` becomes `effect |x: T| -> R ! E ? Q { ... }`. Parenthesize a parameter type that is a union or a callable type, as in `|f: (fn(i32) -> i32)|` or `|v: (A | B)|`. Callable types such as `fn(i32) -> i32` are unchanged.
