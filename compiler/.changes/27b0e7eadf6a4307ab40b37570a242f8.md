`if` is an expression when its `else` chain ends in a final `else`: `let size = if large { 10 } else { 1 }` works, and so does `if let`. Blocks whose value is used, which are the branches of such an `if` and the arm blocks of a match used as a value, yield their last expression. An `if` used as a value without a final `else` reports `PAR0009`, which now suggests adding `else { ... }`.
