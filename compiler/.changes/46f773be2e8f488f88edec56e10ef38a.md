Reworks the `silk.toml` layout before 0.1.0. `[package].source` (default `src`) and `[package].main` (default `main.silk`, or `lib.silk` for a library) replace `root` and `source-root`; `[package].kind` replaces `[build].artifact` and adds `library`, Silk source that `silk build` checks without making an artifact; `version` defaults to `0.0.0`; names may use `_`, `self` and `silk` are reserved package names, and `self`, `sew` and `silk` are reserved dependency names. Native link inputs and the platform supply move to `[native]`, the runtime composition to `[unstable]`. Publishing metadata (`description`, `license`, `repository`, `homepage`, `readme`, `authors`, `keywords`) and `[tool.<name>]` are accepted; `[dev-dependencies]`, `[target]`, `[lints]`, `[test]`, `[bench]`, `[bin]`, `package.include` and non-path dependency sources are refused as not supported yet. Profiles default to the host target, use kebab-case keys, and `dev` and `release` are built in. A dependency's `silk-version` now names the release line it was written for: same minor before 1.0, same major after, and a dev release only matches itself. `silk init` writes the new layout.

## Migration

Rename `[package].root` to `main` (now relative to `source`, which defaults to `src`), `[package].source-root` to `source`, `[build].artifact` to `[package].kind`, `[build].native-link-inputs` to `[native].link`, `[build].platform-supply` to `[native].platform-supply`, `[build].composition` to `[unstable].composition`, and profile `maxMemory`/`codeModel` to `max-memory`/`code-model`. The earlier spellings still work for now. A dependency's `silk-version` must now share the compiler's release line.
