A manifest's release settings are read only from `[release]`; the earlier `[changes]` spelling is no longer accepted. `silk use --help`, `silk set -h` and `silk update --help` print the help. `silk toolchain` and `silk changes` now say which commands replaced them instead of reaching the compiler. `silk set` notes when the pinned version is older than the tool, since that version may not read the manifest. `silk change status` says "1 pending change has no migration note" for a single change.
