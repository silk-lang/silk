Silk versions now belong to `sew`, a separate front door that ships beside the compiler. `sew use` installs the version a project pins, `sew use <version>` installs a version and makes it your default, `sew set <version>` pins the project, and every other `sew` command runs in the selected compiler unchanged. Run as `silk`, the same program forwards every command the same way. The compiler no longer chooses or installs toolchains: `silk toolchain` and `silk +<version>` are gone, and a compiler started directly always runs itself.
