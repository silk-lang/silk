Compile-time evaluation (constant initializers, array lengths such as `[u8; 32]`, static calls) now depends only on the declarations it reads instead of their whole files, so an edit elsewhere in a file that holds a constant or a fixed-size array no longer makes the next check start over.

An edit that closes a constant cycle (`const second: i32 = first` where `first` reads `second`) now reports the cycle on the next check instead of keeping the old value.
