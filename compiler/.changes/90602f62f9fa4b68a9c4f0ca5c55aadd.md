Diagnostics that name a type now name tuples and records, such as `(i32, i32) has no method `frob`` (SEM0010), and types declared inside a `static if`, such as `silk.os_logger.StdoutLogger`. Before, these messages fell back to the code's general text.

Type names in diagnostics spell their module dotted, as imports do: `silk.option.Option<i32>` instead of `silk/option.Option<i32>`.
